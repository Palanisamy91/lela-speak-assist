# Online tense practice: on-demand 50-sentence batches

- The manual **Get free tense examples** action now requests a batch of up to 50 new examples for the selected tense.
- It searches multiple phrase patterns for that tense instead of relying on one phrase (for example, Present Simple no longer depends only on “every day”).
- Results still require a direct Tamil translation, an accepted Creative Commons licence, and a confident tense classification.
- Duplicate English/Tamil sentences are skipped and source attribution is retained.
- The app reports the actual number added if the free public source cannot supply all 50 matching pairs. Existing saved examples remain available offline.
- The public source cannot guarantee exactly 50 matching Tamil-English pairs on every request; the feature attempts up to 50 without inventing sentences.
